# 海岛联订 - 民宿·船班·接驳·活动

海岛民宿联盟、轮渡客服、游客服务中心使用的联订页面，将房型库存、潮汐航班、船票锁座、接驳车、岛上活动名额和退改规则整合到一个轻快直观的联订界面。

## 原始需求

> 做一个给海岛民宿联盟、轮渡客服、游客服务中心使用的联订页面，Svelte + Vite 适合把房态、船班、接驳、活动名额这些联动信息做得轻快直观。页面围绕房型库存、潮汐航班、船票锁座、接驳车、岛上活动名额和退改规则展开。用户选择入住日期、房型、游客人数、往返船班和接驳方式后，要看到房间是否可订、船票是否有座、接驳车是否衔接、活动名额是否充足。页面重点是把房间还有但船停航、船票有座但无法接驳、连住期间需要换房、儿童票价格不同这些组合情况展示清楚。视觉上要有海岛旅游的轻松感，但订单状态、退改提示和停航警告不能被装饰元素淹没。

## 技术栈

- Vue 3 + TypeScript + Vite
- Tailwind CSS（自定义 ocean/sand/coral 色系）
- Pinia 状态管理
- Lucide 图标
- 纯前端，Mock 数据模拟

## 启动方式

### 前置要求

- Node.js >= 18
- pnpm >= 8

### Docker 一键启动（推荐）

```bash
docker compose up --build
```

访问地址：http://localhost:8080

后台运行：

```bash
docker compose up --build -d
```

停止和清理：

```bash
docker compose down
```

### 本地开发启动

#### 1. 安装依赖

```bash
pnpm install
```

#### 2. 启动服务

```bash
pnpm dev
```

访问地址：http://localhost:5173

## 功能说明

- **日期选择**：14 天日历，标注潮汐信息和停航日期
- **房型选择**：展示库存、价格、换房提示
- **游客人数**：成人/儿童分别计数，儿童票价差异提示
- **船班选择**：往返船班时间线，余座进度条，停航警告
- **接驳选择**：衔接状态色标（可衔接/无法衔接/已满）
- **活动名额**：岛上活动时段和剩余名额
- **联动状态面板**：四项状态指示灯 + 冲突详情折叠
- **退改规则**：分项目、分严重等级展示
- **订单摘要**：底部固定栏，价格汇总 + 冲突警告

## 组合冲突展示

| 冲突类型 | 视觉处理 |
|----------|----------|
| 房间有但船停航 | 珊瑚红边框 + 停航图标，联动面板红灯 |
| 船票有座但无法接驳 | 黄色警告条，联动面板黄灯 |
| 连住期间需换房 | "换房"徽标 + 目标房型提示 |
| 儿童票价格不同 | 珊瑚信息栏 + 价格差旁注 |
